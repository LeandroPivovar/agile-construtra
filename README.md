# Agile Construtora - site institucional

Site one-page da **Agile Construtora**: construção de casas, com atendimento pelo WhatsApp.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, como funciona, contato, FAQ)
styles.css   # estilos (azul-marinho e dourado do logo, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # marca em SVG, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Antes de publicar

- **Logo:** no print, o logo aparece cortado no anúncio ("GILE", telhado azul-marinho e dourado). O site usa uma marca simples em SVG (`assets/marca.svg`, telhado com janela) e o nome em texto. Peça o arquivo do logo para substituir.
- **O que a empresa constrói:** o perfil não descreve os serviços. A foto de perfil é uma casa de madeira e, na conversa, a empresa pergunta "Qual a cidade que pretende construir?". Os cards (construção de casas, casas de madeira, projetos, estrutura e cobertura) e a promessa "do projeto à chave na mão" são uma proposta. **Confirme com o cliente**, principalmente se o foco é casa de madeira/pré-fabricada ou alvenaria.
- **Telefone:** o perfil mostra `+55 51 8400-4040` e o anúncio `(51) 98400-4040`. O site exibe o número do anúncio; o link do WhatsApp usa `wa.me/555184004040` (o número do perfil, que é o cadastrado no WhatsApp).
- **Cidade:** o DDD 51 é da região de Porto Alegre - RS, mas o site não cita cidade (a empresa pergunta onde o cliente quer construir). Confirme a região atendida.
- **E-mail:** `maurojmmad@gmail.com`, como está no perfil.
- **Fotos:** de banco de imagens (várias são de casas no estilo norte-americano). Fotos reais de casas entregues, como a da foto de perfil, deixam o site muito mais forte.
- **Depoimentos:** não há seção de depoimentos para não publicar avaliações inventadas.
